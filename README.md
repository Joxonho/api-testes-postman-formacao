## 📌 Sobre o Projeto

Este repositório documenta minha trajetória de aprendizagem em **testes de API REST utilizando o Postman**, como parte da minha formação em Quality Assurance (QA).

O objetivo é desenvolver conhecimentos técnicos e habilidades práticas em testes de software, desde os fundamentos de HTTP até a execução, validação e documentação de testes de API.

O projeto será atualizado progressivamente, conforme a realização das atividades e a consolidação dos conhecimentos adquiridos.

- **Plataforma:** Udemy

## 📚 Conteúdo Programático


### Módulo 1 — Fundamentos de APIs e HTTP
- Conceitos de API e comunicação HTTP.
- Estrutura de URLs.
- Métodos GET, POST, PUT, PATCH e DELETE.
- Operações CRUD.

### Módulo 2 — Documentação Swagger e JSON
- Leitura de documentação de APIs.
- Interpretação de endpoints e parâmetros.
- Estrutura e sintaxe JSON.
- Introdução ao cURL.

### Módulo 3 — Configuração de Workspace e Collections
- Organização de workspaces.
- Criação e estruturação de collections.
- Organização de requisições HTTP.

### Módulo 4 — Execução e Estruturação de Requisições HTTP
- Headers e autenticação.
- Query parameters e path parameters.
- Request body e response body.
- Validação de códigos de status HTTP.

### Módulo 5 — Importação de Requisições e Integração com APIs
- Importação de requisições via cURL.
- Importação de collections.
- Integração com APIs documentadas.

### Módulo 6 — Variáveis e Ambientes
- Configuração de environments.
- Variáveis de ambiente e de collection.
- Parametrização de requisições.
- Reutilização de configurações.

### Módulo 7 — Data Driven Tests com Inteligência Artificial
- Criação de massa de dados.
- Utilização de arquivos JSON e CSV.
- Apoio da inteligência artificial na preparação de dados.

### Módulo 8 — Automação de Testes no Postman
- Introdução aos scripts em JavaScript.
- Utilização de `pm.test`.
- Validação automatizada de respostas.
- Testes de campos, paginação e payloads.

### Módulo 9 — Testes em Escala com Múltiplos Dados
- Collection Runner.
- Execução com arquivos externos.
- Pre-request Scripts.
- Encadeamento de requisições.

### Módulo 10 — IA Generativa do Postman
- Recursos de inteligência artificial do Postman.
- Apoio à criação de testes.
- Análise e revisão de cenários.

### Módulo 11 — Documentação e Relatórios Profissionais
- Execução de collections com Newman.
- Relatórios JSON e JUnit.
- Relatórios HTML com htmlextra.
- Organização e apresentação dos resultados.

### Módulo 12 — Portfólio e Encerramento
- Organização de arquivos.
- Documentação do projeto.
- Publicação no GitHub.
- Apresentação de evidências de testes.
